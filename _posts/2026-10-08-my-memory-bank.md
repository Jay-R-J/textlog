## 一句话定位

> **「我的记忆库」** 是一个把你零碎会忘的东西存进去、忘了就回来问一句、AI翻你自己的记录回答你的工具。不是通用AI聊天框，它回答的依据是你自己写下的内容。

**打开就能用，不用装App，不用配任何东西。**

**[点此打开我的记忆库](https://knowledge-qa-06280.app.workbuddy.host/)**

---

## 三步用法

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 注册 | 用邮箱注册，默认建的是你自己的**私有记忆库** |
| 2 | 存东西 | 三种存法：新增记忆（零散一两条）、导入记忆（粘贴/上传txt/md/csv/json）、抓网页（填网址自动抓取） |
| 3 | 提问 | 回到问答页，用平常说话的方式问，回答下方会列出「来源」，点一下能跳回原文核对 |

> **第一次用？先问它一句「这个网站怎么用」**，它会给你一份完整的使用教程，并标注每条内容来自记忆库里的哪一篇。

## 核心特点

| 特点 | 说明 |
|------|------|
| **会说不** | 库里没有的内容，它直接说「暂无相关信息」，不编、不糊弄 |
| **记忆库优先模式** | 库里有的先按库里答；库里没有的允许AI用通用知识补充，但会**另起一段、明确标注** |
| **默认仅自己可见** | 新增/导入的记忆默认私有，想公开可单独改成「公开」 |
| **权限在数据库层** | 不是页面上藏按钮，而是数据库执行查询时判断，改请求参数也绕不过 |
| **管理员看不到正文** | 管理员只能看聚合数字和用量计数，**看不到任何人的记忆正文和标题** |
| **删除可撤销** | 点删除先移入「回收站」，彻底删要再确认一次 |
| **数据可带走** | 右上角「导出」可导出 Markdown / JSON 到本地 |

用量在记忆库页头部随时能看到。对个人使用是够的。

## 常见问题速查

| 问题 | 原因/解决 |
|------|----------|
| 回答「记忆库中暂无相关信息」 | 库里确实没有，先确认存进去了吗，或换个更口语的问法 |
| 回答出现「以下内容不在记忆库中：」 | 当前是「记忆库优先」模式，这一段依据的是AI通用知识，切回「仅记忆库」即可 |
| 回答很久不出来 | 换个模型试试，深度思考型模型首字可能要等十几秒 |
| 页面空白或一直转圈 | `Ctrl/Cmd + Shift + R` 强制刷新，或关掉标签页重开 |
